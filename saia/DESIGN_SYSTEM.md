# SAIA single-page prototype — design system

- **Purpose:** Local responsive prototype of the SAIA landing page, using the 3D mark as its hero image.
- **Palette:** Page background `#848484`; foreground text `#ffffff`; primary logo front/back planes `#ffffff`; primary logo side planes `#e1dee8`. A synchronized canvas clipped to the `S.A.I.A.` wordmark bounds renders only the overlapping logo area as front/back `#4d4d4d` and side `#3e3e3e`; subtitle and bio use `#848484` per-line fill bands.
- **Typography:** Adobe Fonts kit `aut1aeg` loads `aktiv-grotesk`: Bold (700) for headings, Home body and navigation; Regular (400) for meeting text and directory labels; Regular Italic (400) for Files descriptions. Arial remains only as a loading/failure fallback.
- **Type scale:** Desktop wordmark is `clamp(4.1rem, 9.1vw, 7.3rem)` and content is constrained to `min(78vw, 42rem)`, matching the large red-box reference placement. The subtitle is scaled as a direct visual companion to the wordmark; mobile returns to a wider normal-flow layout.
- **Readability treatment:** Subtitle and bio use inline `.text-band` fragments with `box-decoration-break: clone`, creating tight per-line `#848484` rectangles. The title uses the restored glyph-mask treatment plus Material 3 elevation level-1 text shadow.
- **Layout:** On desktop, the large content column is left-aligned from its left edge at 16.5vw / 40.5svh, matching the red-box placement in the supplied reference. On mobile, the hero crops to `clamp(23rem, 52svh, 33rem)` with a 9rem canvas extension, then content returns to normal flow with a 3.5–5rem top margin: the header intentionally overlaps the tail of the animation while the bio clears it. The transparent 3D canvas is clipped above the persistent navigation band.
- **Motion:** Fixed −45° Y yaw. The outer arrow form rotates counterclockwise at 0.06 rad/s while the four central cylinders stay fixed. Desktop uses a −0.72 Y anchor; mobile uses a small −0.82 Y nudge to expose the subtitle fill band without passing below it. Motion stops under `prefers-reduced-motion`.
- **Home entrance:** Runs once per browser-tab session, tracked in sessionStorage. Navigation back to Home and refresh skip the entrance but keep the regular slow rotation. If storage is unavailable, rendering still works but the entrance may replay. Geometry is fixed at the final 105-unit extrusion depth from the start: 1.5s traces the front SVG contours, 4.5s draws the rear contour and longitudinal side edges, then 1.5s interpolates the solid face/side colors from the canvas background (white for the heading-mask pass) to their final colors. Mesh materials remain opaque and depth-writing throughout; there is no transparency/depth-mode switch at completion, preventing the abrupt final surface reveal. No expansion or depth interpolation occurs. Wireframe materials disable depth test/write and use render order to avoid coplanar flicker. Existing slow counterclockwise arrow rotation runs throughout and afterward; center circles do not spin. Both render passes share geometry/timing. Reduced-motion shows the finished static shape immediately.
- **3D:** Mark scale is 150% of the preceding study scale (14.25/678.7). Maximum prototype perspective: 70° FOV with camera at 8.29 units to retain framing. Extrusion depth 105 SVG units; no bevels; 96 curve segments. Unlit flat vector fills—no blur, lighting, or gradients. Desktop uses the primary renderer plus a pixel-ratio-1 wordmark renderer for the heading glyph mask. At `max-width: 640px`, the mask canvas and secondary render pass are disabled; the heading is solid `#4d4d4d`.
- **Navigation:** Fixed, opaque `#848484` bottom bar with a far-left home link using `house-icon.svg`, followed by four Aktiv Grotesk Bold uppercase links: Meetings, Files, Contact, and Manifesto. A centered flex row uses one responsive, equal `gap` between every item, preserving symmetric outer breathing room at all viewport widths. `--nav-height` reserves a logo-free clearance band at every viewport size.
- **Meetings draft:** `meetings.html` implements the Figma Past Meetings composition: heading, chronological scroll-driven winding image trail in a sticky viewport, selected meeting detail panel, and bottom navigation in Home → Meetings → Files → Contact → Manifesto order. Native vertical scrolling advances the largest foreground image while subsequent images recede along a continuous tightening logarithmic spiral. Additional filler meetings 023–018 make the hooked tail visible; click and arrow-key controls also select meetings. Reduced-motion uses discrete states rather than continuous transforms. Only meeting 027 uses supplied Figma copy; meetings 026–024 have intentional filler labels/descriptions and CSS artwork placeholders awaiting archive assets.
- **Meetings entrance:** After layout and image decoding, cards fade up 20px over 650ms in closest-to-furthest order, with at least 90ms between starts. CSS entrance translate/opacity is separate from JavaScript spiral transforms and depth ordering. Reduced-motion skips the entrance. Versioned CSS/JS URLs prevent cached prior behavior.
- **Files directory:** `files.html` has SAIA Channels (verified 001–026), Tools (Are.na, Wayback Machine, Google Fonts, GitHub), and Resources (empty pending content). Pointer hover and arrow keys highlight white labels in `#e1dee8`, nudging 10px over 240ms ease-in. Open folders nudge 50px; children indent 70px and fade up in 55ms sequence. The same `>` marker rotates 90° when a folder opens and back on close, with a .5rem marker gap. Folder buttons remain mounted so the rotation transitions rather than swapping characters. Directory focus has no box outline; the focus handler supplies the arrow, color change, and nudge as visible keyboard-focus indicators. Enter previews an item, a second Enter opens its URL; clicking a preview card opens the URL. Escape closes preview then folder. All preview images are intentionally solid `#e1dee8` cards. A 300ms ease-in connector precedes a 450ms preview reveal. Description uses Aktiv Grotesk 400 italic with reserved full-text geometry and cancellable typewriting. Mobile stacks the directory and preview with a horizontal rule above the card; subfolders hide scrollbars and page at most eight entries at a time with left-aligned up/down indicators. Reduced-motion removes motion and typing. Navigation label is Files universally; Resources remains a subfolder. On mobile Home, a canvas-colored mask begins at the body-copy block and spans the full viewport width to the bottom, with its top .35rem above the body-copy block to match the annotated boundary, preserving readable copy over a calmer field.
- **Shared typography trial (2026-11-10):** `typography.css` loads after each page stylesheet. Shared page headings scale 28–40px (1.1 leading), body/descriptions 15–16px (1.5 leading), and interface labels/links/navigation 13–14px. Home display wordmark remains bespoke. The trial's layout overrides were removed on 2026-11-12: Home uses its original mobile hero dimensions and content flow; Meetings uses its original card size, spacing and description width. `mobile-fit.js` shifts only overflowing mobile content upward enough to clear navigation by 16px, without scaling the page or changing text size. Files retains italic captions. Tested initial content at 320×568, 390×844, 640×900, 768×1024, 1440×900 and 1920×1080; not a complete all-content/zoom/landscape certification. This shared override can be removed to revert the trial without rewriting original page rules.
- **Files overview:** With all folders closed, the vertical list is offset down/right from FILES and rendered at 3× scale (2.5× at widths ≤380px to prevent clipping). Opening any folder springs to an intermediate 2× browsing stage. Selecting an item springs to the original 1× scale/position; the connector and preview start after the 700ms shrink settles. Escape from a preview restores 2× browsing; closing the folder restores the overview. Transitions use a 700ms overshooting cubic-bezier spring-like curve. Pending preview work is cancelled when the selection/stage changes. The heading does not move; reduced-motion makes the change immediate.
- **Files subfolder windows:** No visible scrollbar. Show at most eight entries; adapt downward on short viewports so end indicators fit. Left-aligned ↑/↓ buttons use inherited Regular typography and indicate previous/more entries at the top/bottom, respectively. Arrows page the window, and keyboard navigation moves seamlessly through all items. Hidden-window items do not enter tab order. Viewport resizing and stage transitions recalculate capacity.
- **Reuse:** The removed heading glyph-mask pattern is saved as global skill `webgl-text-glyph-mask` at `~/.pi/agent/skills/webgl-text-glyph-mask/`, with a reusable Three.js reference implementation.
- **Accessibility:** Canvases are decorative; fallback SVG has descriptive alt text. Content uses semantic heading/header/article elements; navigation is a labelled semantic `nav` with visible keyboard focus.
